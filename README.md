# حساباتی خۆم (Hesabati Xom) 📱📦

ئەپڵیکەیشنی ئەندرۆید بە زمانی کوردی (سۆرانی) بۆ ژمێریاری و بەڕێوەبردنی حساباتی مانگانەی بەریدی گەیاندن (Delivery Parcels) و پەیج و کۆمپانیاکانی کارکردن بە دیناری عێراقی (IQD).

---

## 🚀 شێوازی کارکردنی ئەپەکە
- 📸 **ژمێرەری ئۆتۆماتیکی بەرید**: هەموو وێنەیەک کە دەگیرێت یان لە گەلەری هەڵدەبژێردرێت، خۆی ٢٥٠ دیناری عێراقی ئەژمار دەکات (نرخەکەش دەگۆڕدرێت).
- 🔢 **کۆی گشتی بەرید و پارە**: پیشاندانی ژمارەی بەریدەکانی ئەم مانگە و کۆی گشتی پارە (بۆ نموونە: ١٠٠ بەرید = ٢٥,٠٠٠ د.ع).
- 🔄 **سفڕکردنەوە بەیەک کلیک**: دوگمەی پاکتاوکردن و سفڕکردنەوەی ژمێرەر بۆ سەرەتای مانگ یان سووڕی نوێ.
- 🏢 **تۆماری پەیج و کۆمپانیاکان**: تۆمارکردنی ناوی پەیجەکان و ژمارەی مۆبایلیان، پەیوەندیکردنی خێرا، و حساباتی جیاواز بۆ هەر پەیجێک بە جیا.
- 🖤 **دیزاینی ڕەش و سپی سادە (Minimalist B&W)**: زۆر سادە، خێرا و بێ قەرەباڵخی.
- 🔒 **ئۆفلاین (100% Offline)**: داتاکان لەناو مۆبایلەکەتدا دەمێننەوە بێ پێویستی بە ئینتەرنێت.

---

## ⚡ دروستکردنی فایلی APK بە شێوازی ئۆتۆماتیکی لە ڕێگەی GitHub Actions
ئەم پڕۆژەیە بە فایلی کۆنفیگی `.github/workflows/build-apk.yml` ئامادەکراوە بۆ ئەوەی هەرکاتێک پڕۆژەکەت ناردە سەر GitHub، **خۆی بە شێوەیەکی ئۆتۆماتیکی فایلی APK دروست بکات**:

### هەنگاوەکانی بردنە سەر گیتحەب (Push to GitHub):
١. لە سەر ماڵپەڕی [GitHub.com](https://github.com) گەنجینەیەکی نوێ (New Repository) دروست بکە بە ناوی `hesabati-xom`.
٢. فەرمانەکانی خوارەوە لە تێرمیناڵ لێبدە بۆ ناردنی کۆدەکان:
```bash
git remote add origin https://github.com/USERNAME/hesabati-xom.git
git branch -M main
git push -u origin main
```

٣. **داگرتنی فایلی APK لە گیتحەب**:
- بچۆ سەر بەشی **Actions** لە گیتحەبەکەت.
- دەبینیت وۆرکفلۆی **Build Android APK** خۆی دەستی پێکردووە و سەوز دەبێت.
- کلیل لەسەر کارەکە بکە و لە بەشی **Artifacts** فایلی **`Hesabati-Xom-APK`** ڕاستەوخۆ دابگرە بۆ ناو مۆبایلەکەت!

---

## 🛠️ دروستکردنی فایلی APK لەسەر کۆمپیوتەر یان تێرمیناڵ
ئەگەر ویستت ڕاستەوخۆ لەسەر سیستەمی خۆت دروستی بکەیت:
```bash
./gradlew assembleDebug
```
فایلی ئەی پی کەی لەم ناونیشانە دەبێت:
`app/build/outputs/apk/debug/app-debug.apk`

## 🧰 تەکنەلۆژیاکان (Tech Stack)
- **Language**: Kotlin 2.0
- **UI**: Jetpack Compose (Material 3 - B&W Minimalist)
- **Database**: Android Jetpack Room (SQLite)
- **Image Handling**: Coil Compose
- **CI/CD**: GitHub Actions (Ubuntu / Temurin JDK 17)
