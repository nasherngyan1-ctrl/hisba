# حساباتی خۆم (Hesabati Xom) 📱📦

ئەپڵیکەیشنی ئەندرۆید بۆ بەڕێوەبردنی حساباتی مانگانە، ژمێرەری ئۆتۆماتیکی وێنەی بەرید (Delivery Parcels)، تۆماری پەیج و کۆمپانیاکانی کارکردن بە ناو و ژمارەی مۆبایل، و بەڕێوەبردنی خەرجی و داهات و دەفتەری قەرزەکان بە دیناری عێراقی (IQD).

## تایبەتمەندییە سەرەکییەکان (Features)
- 📦 **ژمێرەری ئۆتۆماتیکی وێنەی بەرید**:
  - گرتنی وێنەی بەرید بە کامێرا یان دیاریکردن لە گەلەری مۆبایل.
  - ئەژمارکردنی ئۆتۆماتیکی ٢٥٠ دیناری عێراقی (یان هەر نرخێکی دیاریکراو) بۆ هەر وێنەیەک.
  - پیشاندانی کۆی بەریدەکان (بۆ نموونە: ١٠٠ بەرید) و کۆی گشتی پارە (٢٥,٠٠٠ د.ع).
  - سفڕکردنەوەی ژمێرەر تەنها بەیەک کلیک (One-Click Reset) بە دیالۆگی دڵنیابوونەوە.
- 🏢 **تۆماری پەیج و کۆمپانیاکان**:
  - تۆمارکردنی ناو، ژمارەی مۆبایل، و تێبینی بۆ هەر پەیج یان شوێنێکی کارکردن.
  - پەیوەندیکردنی خێرا (Call) لە ناو ئەپەکە بە ژمارەی مۆبایل.
  - حساباتی جیاواز و ورد بۆ هەر پەیجێک: ژمارەی بەریدەکانی و کۆی پارەی شایستە.
  - پاکتاوکردنی حساباتی پەیج.
- 💰 **خەرجی و داهاتی مانگانە**:
  - پۆلێنکردنی خەرجییەکان (خۆراک، کرێ، هاتوچۆ و بەنزین، کارەبا، هیتر).
  - بەراوردکاری و باڵانسی تەواوی مانگ.
- 🤝 **دەفتەری قەرزەکان (قەرزداری و قەرزخوازی)**:
  - تۆمارکردنی "قەرزم لایەتی" و "من قەرزارم" بە ناو و بڕی پارە.
  - دیاریکردنی قەرز وەک پاکتاوکراو بە یەک کلیک.
- 🔒 **تەواو پارێزراو و ئۆفلاین (100% Offline)**:
  - بەکارهێنانی Room SQLite بۆ پاشەکەوتکردنی تەواوی داتا و وێنەکان لەسەر مۆبایل بێ پێویستی بە ئینتەرنێت یان دروستکردنی ئەکاونت.
- 🌐 **ڕووکاری تەواو کوردی (RTL)** بە ستانداردەکانی ماتیریال ٣ (Material 3).

## تەکنەلۆژیاکان (Tech Stack)
- **Kotlin** & **Jetpack Compose**
- **Material Design 3 (M3)**
- **Android Jetpack Room Database** (KSP)
- **Coil** بۆ پیشاندانی وێنەکان
- **Coroutines & Flow** بۆ نوێبوونەوەی کاتی ڕاستەقینە

## دروستکردنی فایلی APK (Build APK)
دەتوانیت لە ڕێگەی تێرمیناڵەوە یاخود لە مێنیوی سەرەوەی AI Studio فایلی APK دروست بکەیت:
```bash
gradle :app:assembleRelease
```
فایلی APK لەم شوێنە دروست دەبێت:
`app/build/outputs/apk/debug/app-debug.apk` یاخود `release/app-release-unsigned.apk`.
